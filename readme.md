# Dragones Literarios

Juego de trivia literaria donde te enfrentas a dragones guardianes. Cada dragón protege un género literario y te hace preguntas para poner a prueba tu sabiduría. Si aciertas, le quitas escamas. Si fallas, pierdes pergaminos.

## Cómo se juega

1. Cada dragón tiene **3 escamas**. Tú tienes **3 pergaminos**.
2. El dragón te hace una pregunta de literatura.
3. Si aciertas: el dragón pierde una escama.
4. Si fallas: pierdes un pergamino.
5. Derrota al dragón para avanzar al siguiente nivel.
6. Si pierdes todos tus pergaminos, vuelves a empezar el nivel.
